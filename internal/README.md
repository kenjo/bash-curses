# Internal docs

These notes are for contributors and maintainers. User-facing library
documentation lives in [`../docs/README.md`](../docs/README.md).

- `design.md` — architecture, data model, input/mouse internals, current
  behavior, and API deviations.
- `mouse-internals.md` — mouse wire formats, decode/merge internals, test
  coverage, and tmux testing notes.
- `testing.md` — full test suite, parity tools, and tmux caveats.
- `example-deviations.md` — current accepted example parity differences from
  the C reference binaries.
- `api-matrix.md` — ncurses API surface exercised by the reference corpora and
  current project scope.
